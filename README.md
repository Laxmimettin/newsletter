
# ✉️ Newsletter Signup Modal

A modern, responsive newsletter signup popup built using HTML5, CSS3, and JavaScript. The modal appears automatically after a short delay and allows users to enter their email address with basic validation.

## ✨ Features

- Attractive UI with gradients and smooth animations.
- Automatic popup after 3 seconds.
- Email input with format validation.
- Close button and overlay-click dismissal.
- Escape key support to close the modal.
- Success message after valid submission.
- LocalStorage prevents the popup from reappearing after dismissal.
- Responsive design for mobile and desktop.

## 🛠️ Technologies Used

- HTML5 – Page structure and signup form.
- CSS3 – Styling, gradients, animations, and responsive layout.
- JavaScript – Timer, form validation, modal controls, and LocalStorage.

## 🚀 How to Run

1. Download or clone the project.
2. Keep all four files in the same folder.
3. Open `index.html` in your web browser.
4. Wait 3 seconds for the newsletter popup.
5. Enter an email address to test validation and the success message.

## 🎯 Learning Objectives

- Understand modal creation and visibility control.
- Practice JavaScript `setTimeout()`.
- Validate email input using regular expressions.
- Handle click and keyboard events.
- Store dismissal status using LocalStorage.

## 🔮 Future Enhancements

- Connect the form to a backend API.
- Store subscriber email addresses in a database.
- Send confirmation emails to subscribers.
- Add newsletter subscription management.

## 📝 Note

This is a frontend practice project. The form displays a success message but does not save email addresses to a server or send actual newsletters.
